# Lucid interface

Extend the established living robot office. Keep its warm artwork, navy and lavender panels, peach actions, Lexend interface type and JetBrains Mono code type.

## App library

The small four-square button sits immediately before the existing settings control in the sidebar header. The library uses the existing `--night`, `--night-2`, `--night-3`, `--ink`, `--ink-2` and `--accent` tokens, desktop app icons, compact category controls and unboxed app tiles. A native dialog provides modal focus and an explicit Close action. On narrow screens, the app grid sits above the detail view.

Search includes familiar service names for the fictional counterparts. Work-only surfaces are described honestly. Available demos run original app code in a disposable document, separately from real robots and backend actions. Switching apps or closing the library removes that document.

Dialog entry uses 240 ms opacity and a subtle scale on `cubic-bezier(.23,1,.32,1)`; controls use 130 ms color and press feedback. Reduced motion removes scale and entrance motion. Shared open/switch sound cues respect Lucid's existing sound settings.
